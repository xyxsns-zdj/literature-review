# Literature Review Skill

A Cowork AI skill that guides you through the complete 6-step literature review writing process, based on **Galván & Galván (2017) — Writing Literature Reviews (7th ed., Routledge)**.

## Features

- **Step-by-step guided workflow** — 6 steps from topic selection to final manuscript
- **AI-powered literature search** — the AI uses WebSearch to find real papers with real URLs; you just click to select
- **Visual selection interface** — every decision uses AskUserQuestion with clickable options (no typing required)
- **Zotero integration** — structured import and organization guidance
- **Multi-format output** — Word (.docx) and LaTeX (.tex) with APA 7th formatting
- **Built-in editing checklist** — 48-item comprehensive self-editing checklist (Appendix A)

## Six Steps

| Step | Name | Key Output |
|------|------|------------|
| 1 | Determine Review Type | Term Paper / Thesis / Journal selected |
| 2 | Select & Refine Topic | Refined topic statement + AI-curated literature pool |
| 3 | Screen & Organize Literature | Screening table + Zotero library |
| 4 | Deep Analysis | Analysis tables + category summaries |
| 5 | Synthesize & Write Draft | Complete first draft with thesis statement |
| 6 | Edit & Finalize | Final manuscript (Word/LaTeX + PDF) |

## Installation

1. Download `SKILL.md`
2. Import into your Cowork skills directory
3. Trigger by typing `/literature_review` or "write literature review"
